# 3강. 일차결합, 생성(Span), 일차독립

지난 시간: 벡터공간 V와 부분공간
오늘의 질문: 몇 개의 벡터로 공간 전체를 표현할 수 있는가?

<!-- page: 2 -->
# 일차결합 (Linear Combination)

정의. 벡터 v1, ..., vk ∈ V 와 스칼라 c1, ..., ck 에 대해
c1v1 + c2v2 + ... + ckvk
를 v1, ..., vk 의 일차결합이라 한다.

<!-- page: 3 -->
# 생성 (Span)

정의. span{v1, ..., vk} = { c1v1 + ... + ckvk : c1, ..., ck ∈ R }
v1, ..., vk 의 모든 일차결합의 집합.

성질. span{v1, ..., vk} 는 V의 부분공간이다.

예) R^2 에서 span{(1,0), (0,1)} = R^2

<!-- page: 4 -->
# 일차독립 (Linear Independence)

정의. c1v1 + ... + ckvk = 0 이면 c1 = ... = ck = 0 일 때,
v1, ..., vk 는 일차독립이라 한다.
그렇지 않으면 일차종속이라 한다.

★ 중요: 자명한 해(trivial solution)만 존재하는가?

<!-- page: 5 -->
# 예제

예1) (1,2), (2,4) 는 일차종속: 2(1,2) - (2,4) = 0
예2) (1,0), (0,1) 은 일차독립

정리. v1, ..., vk 가 일차종속 ⇔ 어떤 vj 가 나머지 벡터들의 일차결합으로 표현된다.
